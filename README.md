# PIXEL KITCHEN

브라우저 이미지 필터 실험실. 3×3 커널·Sobel·문턱값을 최대 4단계로 연결하고, 합성 목표를 재현하는 기존 5개 과제를 제공합니다.

## 사용

- 원본·목표·결과·차이 지도·좌우 비교를 선택합니다. 중간 결과는 `오른쪽 결과`에서 고릅니다.
- 히스토그램은 선택한 이미지의 밝기·R·G·B·α 분포를 계산합니다. RGB/밝기는 완전 투명 픽셀을 제외하고, α는 전체 픽셀을 셉니다.
- 자유 실험에서 `JSON 내보내기` / `JSON 가져오기`로 필터 설정을 옮깁니다. 가져오기 후 `파이프라인 실행`을 누릅니다.
- `현재 설정 저장`으로 이 기기에 번호 프리셋을 최대 8개 저장합니다. `불러오기`·`선택 삭제`·`전체 삭제`를 제공합니다. 이미지나 이름·경로는 프리셋에 포함되지 않습니다.
- 과제에서는 레시피 저장·가져오기·불러오기를 사용할 수 없습니다. 허용 연산과 실제 MAE/RMSE·α 조건을 충족한 실행만 다음 과제를 엽니다.

PNG·JPEG·WebP ≤ 8 MiB, 디코딩 결과 ≤ 24MP, 처리 ≤ 720×480. 최종 PNG 다운로드는 현재 계산을 완료한 결과만 내보냅니다. 모바일은 미리보기가 편집기 앞에 있으며 `화면` 선택과 `실행`을 제공합니다.

## 개인정보와 설정 형식

이미지는 브라우저 메모리에서 처리하며 업로드·저장하지 않습니다. 네트워크 API·계정·추적·쿠키가 없습니다. 페이지 이동 시 픽셀과 과제 진행을 비우며, BFCache 복귀는 시드 17의 첫 과제로 시작합니다. 호스팅 로그는 앱 처리와 별개입니다.

명시적으로 저장한 프리셋만 `pixel-kitchen-presets-v1`에 남습니다. 저장 데이터는 정확히 버전·번호·필터 설정이며 최대 8개/64 KiB입니다. 전체 삭제는 이 키만 지웁니다. 손상된 저장 데이터는 자동 덮어쓰기하지 않고 삭제로 초기화할 수 있습니다. 저장 차단·용량 초과는 화면에 표시됩니다. 여러 탭은 마지막 성공한 저장을 사용합니다.

JSON 레시피는 최대 8 KiB이며 정확히 `{version:1,model:"pixel-kitchen-byte-v1",stages:[...]}`입니다. 지원하지 않는 버전·추가/누락 필드·범위 밖 숫자를 거절하고, 적용 전 현재 이미지의 40M 계산 예산을 확인합니다. 커널 필드는 `kind,kernel,divisor,bias,gray`, Sobel은 `kind,direction,gain`, 문턱값은 `kind,cutoff`입니다. 필터 이름·파일·시드·픽셀·진행 정보는 허용하지 않습니다.

기존 과제 통과는 페이지 메모리에만 유지합니다. 저장 프리셋·가져오기·샘플 처리는 완료 과제가 아니므로 갤러리 `web-lab-progress-v1` 요약을 작성하지 않습니다. 공개 순위는 없습니다.

## 실행과 확인

Node.js 22 이상. 외부 패키지가 필요하지 않습니다.

```sh
npm run dev -- 0
npm test
npm run check
```

표시된 로컬 URL을 엽니다. 정적 서버는 업로드/API를 처리하지 않습니다.

1. 첫 과제(시드 17)에서 밝기 6을 실행하면 실패합니다. 밝기 12를 실행하면 MAE/RMSE 0으로 두 번째 과제가 열립니다.
2. 자유 실험에서 가우시안 → Sobel 크기(증폭 1) → 문턱값(60)을 구성해 실행합니다. 결과/좌우 비교와 각 단계 히스토그램을 확인합니다.
3. 현재 설정을 저장하고 JSON을 내보냅니다. 새로고침 후 자유 실험에서 프리셋을 불러와 실행합니다. 개인 사진은 복원되지 않습니다.
4. 순서를 초기화한 뒤 JSON을 가져와 실행합니다. 버전 2 또는 추가 `image` 필드가 있는 파일은 거절되며 현재 설정이 유지됩니다. 선택/전체 삭제를 확인합니다.

계산 의미·저장 정책은 [구조](architecture.md)와 [결정 기록](docs/decisions.md), 정확한 검증 상태와 메인용 화면 확인 절차는 [검증 기록](docs/verification.md)에 있습니다. 선택적 기존 Chromium QA는 `tools/browser-smoke.js`, `browser-limits.js`, `browser-bfcache.js`이며 이번 브라우저 검증은 메인 담당입니다. 이번 로컬 변경의 원격 CI·배포·실기기 검증은 NOT_RUN입니다.

각 패스는 RGB를 바이트로 반올림·제한하며 α를 유지합니다. Rec.709는 인코딩된 RGB에 적용합니다. 끝 픽셀 반복이며 투명 이웃의 RGB도 커널에 포함됩니다. MAE/RMSE는 픽셀 바이트 오차입니다. 자세한 계산 한계는 구조 문서에 기록합니다.
